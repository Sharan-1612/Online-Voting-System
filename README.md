# Tamil Nadu Online Voting System

A frontend-based online voting system prototype built using HTML, CSS, and JavaScript. The project demonstrates a simple digital voting workflow including voter authentication, candidate selection, vote casting, and election results.

## 🌐 Live Demo

👉 https://sharan-1612.github.io/Online-Voting-System/

## ✨ Features

- 🔐 Voter authentication using Voter ID
- 🗳️ Candidate selection and vote casting
- 🚫 Prevents a voter from voting more than once during the session
- 📊 Election results with vote counts and percentages
- 🏆 Leading candidate / winner announcement
- 🎨 Responsive and user-friendly interface
- 🌄 Tamil Nadu inspired visual design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- GitHub Pages

## 🗳️ Voting Workflow

1. Enter a registered Voter ID.
2. Authenticate the voter.
3. Select a candidate.
4. Cast the vote.
5. View the election results.
